# Сторож real-best

Раз в 15 минут проверяет снаружи, отвечают ли витрина, кабинет и сервис фабрики.
Если нет — пишет владельцу в Telegram.

Репозиторий открытый нарочно: у публичных репозиториев минуты GitHub Actions
бесплатны без лимита, а у приватных их 2000 в месяц, и сторож молча вставал бы
в конце месяца. Внутри нет ничего закрытого — только три адреса, доступные
всему интернету. Токен бота лежит в секретах репозитория.

Зачем отдельный сторож, если на сервере уже есть свой: тот живёт на том же
сервере, за которым следит. Умер сервер целиком — сообщения не будет вообще.

Исходник файла проверки — в приватном репозитории фабрики,
`factory/server/watch/uptime.yml`. Правки вносить там.
